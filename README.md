# 🎬 Movie Quiz Game

A web-based interactive quiz game inspired by Netflix style movie experiences.  
This project allows users to log in, select a movie, and play a timed quiz based on it, with interactive gameplay features such as power-ups and a leaderboard system.

This project was developed as part of a university assignment focused on web development, JavaScript functionality, and team collaboration.

---

## Project Overview

The goal of this project was to build a fully functional web application game using:

- HTML
- CSS
- JavaScript

The application simulates a “movie quiz experience” where users can test their knowledge after selecting a movie, similar to interactive streaming platform features.

Users can:
- Create an account or log in
- Select a movie from a list
- Play a timed quiz based on the selected movie
- Use in-game power-ups
- Compete for high scores on a leaderboard
